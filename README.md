# Li-Fi Explorer

App pédagogique 100 % logicielle pour comprendre et simuler le **Li-Fi** (communication de données par la lumière).

## Ce que fait l'app
- Explique le principe du Li-Fi en 7 étapes illustrées
- Simule une transmission de message par lumière (message → binaire → LED → réception → décodage)
- Compare Li-Fi et Wi-Fi
- Présente des cas d'usage concrets (hôpitaux, avions, retail, musées, domotique)
- Quiz de 10 questions avec score et meilleur score sauvegardé
- Anecdotes et chiffres clés sur le Li-Fi

## Points clés
- Aucun matériel requis, aucune vraie transmission lumineuse : tout est simulé
- PWA installable (Android en priorité, adapté tablette/desktop)
- Fonctionne hors ligne une fois installée (service worker)
- Aucune dépendance externe, aucun coût d'hébergement (Vercel/Netlify en gratuit)

## Ouvrir le projet
Ouvrir `index.html` via un serveur local (ex. `python3 -m http.server`) ou déployer le dossier tel quel sur Vercel/Netlify.
